# 鋼柱分析設計 Steel Column Lab

繁體中文、無外部依賴的鋼柱 ASD 構材計算網頁。開啟 `index.html` 即可使用。

## 計算依據

採臺灣《鋼構造建築物鋼結構設計技術規範》容許應力設計法：96-06-11 修正發布、99-09-16 修正第 13.2 節。2026-10-01 查核官方公告。使用第 4、6、7、8 章。ASD 第 6.4 節引用極限設計法附錄 2 的彈性扭轉挫屈應力，再轉換等效長細比回代 ASD 曲線，未混用 LRFD 折減係數。

規範：https://www.nlma.gov.tw/ch/legislation/regsearch/7176
法規：https://glrs.moi.gov.tw/LawContent.aspx?id=GL000143

## 功能

- H 型鋼（熱軋／連續銲接）、等厚銲接箱型柱、圓管。
- 43 組常用尺寸：19 組 H、12 組箱型設計預設、12 組圓管。選單以 mm 顯示，自動轉成 cm，手動修改後切為自訂；材料與載重保持不變。
- 尺寸、材料、雙軸有效長度、側撐間距、H 柱扭轉支撐與 N–Mx–My 即時檢核。
- 斷面尺寸圖、逐項檢核、容許純軸壓力、軸彎互制及逐步計算。
- 無效輸入清空結果；細長肢材超出本版範圍時不提供容量合格結論。
- 響應式畫面、鍵盤輸入、欄位提示、手機結果捷徑。

## 原始程式解析

來源為使用者提供的 SteelColumn_20121009_SourceCode.zip，主要流程位於 FormMain.vb：

1. CAL_Sect：斷面 A、I、S、r、J。
2. CAL_ENGINE：分類、容許彎應力、側向扭轉挫屈、剪應力容量。
3. CAL_ENGINE2：雙軸 ASD 軸壓曲線、作用應力與第 8.2 節互制。
4. _OUTPUT_ALL：報表。

主要修正：kc 由錯誤乘法改為除法；箱型柱寬厚比採淨寬；圓管軸壓 232/Fy 與純彎曲 630/Fy 分開；細長肢材不直接套 0.6Fy；互制非正分母、彎矩正負號與無效輸入防護；H 柱增加扭轉挫屈；箱型第 6.7 節曲線保留。

原程式另有 C/T/L、Access 型錄與手動性質輸入。本版不包含這些型式及其撓曲扭轉處理，不上傳原始 ZIP、執行檔或資料庫。

## 使用範圍

輸入 ASD 單一載重組合之構材內力，cm、kgf/cm²、tf、tf·m。H 型腹板有軸壓時採均勻受壓 68/√Fy 上限保守篩選。鋼材均質、等斷面、連續連接、荷重通過剪力中心，H 型 Fy≤4550 kgf/cm²。斷面以直角板件算，不含型鋼圓角。

細長肢材有效斷面、C/T/L 型鋼、構架二階效應、載重組合產生、剪力、接頭、柱腳、銲道、耐震構架與耐火不在本版自動檢核範圍。通過僅指已實作的單構材項目。圓管雙軸彎矩取絕對值線性相加，偏保守。

## 驗證

執行 `node checks/engineering-checks.cjs`。20 項測試涵蓋數值參考、容量邊界、彎矩符號、長細比、ASD 分段曲線、箱型專用曲線、圓管適用性、kc、非正放大分母與無效輸入。JavaScript 語法及本地資產路徑已檢查；未完成真實瀏覽器視覺 QA。WebMCP 屬選用讀取工具，當前環境無可用的受支援驗證情境，未宣稱其實機驗證通過。

## GitHub Pages

可將 `dist` 內容放於儲存庫根目錄，從 main / root 發布；或將此專案上傳並透過靜態部署流程發布 `dist`。所有連結採相對路徑，可掛於 GitHub Pages 專案子路徑。

台灣尺寸來源：東和鋼鐵 2024 型錄 https://www.tunghosteel.com/product/detail/2 及美亞碳鋼鋼管型錄 https://www.mayer.com.tw/zh-tw/download/1 。箱型為銲接設計預設，非型錄庫存。圓管僅借用國內型錄幾何尺寸，不代表配管鋼材自動符合結構用途；鋼種、Fy、厚度公差及結構適用性須確認。選單不自動改動材料強度、長度或內力，A/I/S 仍以幾何計算、不含型鋼圓角。

## Word 計算報告

網頁「匯出 Word 計算報告書」產生原生 Office Open XML `.docx`，包含工程／構材／計算者、當下輸入、逐項檢核、完整展開的計算過程、適用限制與來源。報告以相同即時計算結果輸出，不另建計算引擎。無效輸入禁止匯出；超限斷面保留需另行分析狀態。瀏覽器本機生成，不使用外部轉檔服務。
